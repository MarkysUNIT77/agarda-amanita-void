### 📝 Description
Входной управляющий шлюз безопасности и веб-интерфейс вселенной **A.G.A.R.D.A.** (Проект МУХОМОР). Модуль развертывается на *Hugging Face Spaces* (порт 7860), анализирует входящие запросы на предмет *Prompt Injection* и передает очищенные данные в контур «ОВОЩНОЙ САД».

### ⚙️ Интеграционная карта портов
* **Port 7860:** Главный шлюз управления и интерфейс Gradio (`agarda-amanita-void`)
* **Port 7862–7865:** Дочерние сервисы экосистемы (выжимка энтропии, утилизация инжектов, балансировка и мутация весов)
